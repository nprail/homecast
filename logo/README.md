# Homecast logo

Concept 6, "Waveform roof": a waveform that spikes into a roof peak, resting on a floor line.

| File | Use |
|---|---|
| `homecast-mark.svg` | Mark for dark backgrounds (teal + amber) |
| `homecast-mark-light.svg` | Mark for light backgrounds (dark teal + dark amber) |
| `homecast-app-icon.svg` | App icon source, 1024 x 1024. Platforms apply their own corner masks, so export a square version without rounded corners for iOS/Android |

## Wordmark

"Homecast" in Space Grotesk Bold, letter-spacing -0.02em, set in #F1F3F7 on dark or #14171C on light. Not outlined in the SVGs, so convert text to paths before shipping.

## Colors

- Teal `#4FD1C5` (dark UI), `#0F766E` (light UI)
- Amber `#F5B544` (dark UI), `#B7791F` (light UI)
- Icon background `#4FD1C5`, mark `#04201D`
